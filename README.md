# Exam Preparation Materials

This repo contains materials to help you prepare for the exam. Specifically, there is one study guide .html file per day of the course. 

The 2025 exam script is available [here](https://shortcourses.lse.ac.uk/pluginfile.php/536509/mod_resource/content/1/me314_2025_exam.pdf). You will need to be logged in to Moodle to access it, and we ask that you do not share it beyond other members of this class. 

Please remember that the 2025 exam was for the 2025 class -- there may be some topics we de-emphasized or added this year.
